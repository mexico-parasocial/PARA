# P7 - replace the HTML string client on web

Estimate only. No implementation has started and no agreement to start it was requested in the handoff.

The current web chat is an `iframe srcDoc` generated by `matrix-client.ts`. Moving it to a React component with `matrix-js-sdk` and `initRustCrypto` is roughly **15-25 engineering days plus 3-5 days of device/browser QA**, assuming the current homeserver and MAS configuration stay stable. A workable split is 3-4 days for session and encrypted-room lifecycle, 5-8 for timeline and media, 3-5 for reactions/receipts/typing/replies and reports, and 4-8 for migration states, accessibility, tests and cleanup. The range includes avoiding token leakage into page HTML and keeping the existing unencrypted room readable during migration.

The main unknown is encrypted web interoperability with the native Rust SDK and Element across device verification and key recovery. Prove that in a small technical spike before committing to the lower end of the range. Do not remove the mobile WebView fallback until P6 and the room migration have device acceptance.

P7 is a separate project decision. The present task leaves the iframe in place and leaves `CHAT_ENGINE` at its WebView default.
